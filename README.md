Repository for test automation of anti-fraud

# Test data generation API

In order to check antifraud rules manually we need to have an opportunity to fill the databases with required data beforehand.
The process is the same as we already use during automatic test launches, but the data is persisted in the databases until it is no longer needed.
When checks are finished and the data is not needed anymore it may be removed.

To solve these tasks we can use the API:

1. To return all rule names that support test data generation via API:

```shell
curl https://generator.vindex-test.risk-vantagefx.com/v1/rules
```

2. To generate data for all cases of the defined rule:

```shell
curl -X POST https://generator.vindex-test.risk-vantagefx.com/v1/rules/{rule-name}
```
`{rule-name}` is one of the returned values of the previous API response:

3. To return data that is generated by a POST request.
```shell
curl https://generator.vindex-test.risk-vantagefx.com/v1/rules/{rule-name}
```

4. To delete data for the rule:
```shell
DELETE https://generator.vindex-test.risk-vantagefx.com/v1/rules/{rule-name}.
```
